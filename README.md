*В разработке.

Два микросервиса, каждый со своей БД и синхронизацией через Kafka.

# tx-processor
Принимает транзакции (зачисления и списания) пользователей. В БД хранятся транзакции и балансы пользователей. Пользователей примерно миллиард и они любят в день зарплаты активно запрашивать баланс. Поэтому в этот сервис для просмотра баланса мы их не пускаем.
# balance-viewer
Сервис просмотра баланса. Баланс принимаем через _Kafka_ из сервиса **tx-processor**.

### Интересное:
- _Outbox_ через _Kafka_ с идемпотентностью (в коде и в настройках _Kafka_).
- Частичный индекс на таблице для _Outbox_.
- _UUIDv7_.
- _Docker_ для _PostgreSQL_, _Kafka_ и _Kafka-UI_.
- _Flyway_ для создания нужных таблиц.
- _Spotless_ для форматирования.
- _Errorprone_ для статического анализа.
- _Gradle_ на _kotlin-dsl_ с настройкой версий в _libs.versions.toml_ и отдельным модулем на каждый сервис.
